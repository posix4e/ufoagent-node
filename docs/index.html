UFOAgent

Run Microsoft UFO2 on your Windows machine with short-lived LLM credentials — fetched and refreshed automatically. You never handle a key.

⬇ Download for Windows View source
Open-source · Apache-2.0 · auto-updating · all releases

How it works

STEP 1

Download & install

Run ufoagent-setup.exe. It installs UFO2 + the ufoagentd daemon and registers a background task.

STEP 2

Link your machine

The agent shows a short pairing code. Approve it in your dashboard — no keys to copy.

STEP 3

UFO2 just runs

The daemon keeps a fresh credential in UFO2's agents.yaml and calls your LLM provider directly.

Why

  • No long-lived keys on disk — the control plane vends short-lived credentials; the machine token is stored with Windows DPAPI.
  • Signed & auto-updating — the daemon self-updates from signed GitHub Releases.
  • Bring your own Windows — install on any Windows 10/11 box.
  • Pure standard library — the daemon has zero runtime dependencies.

For developers

UFOAgent is a control plane (Cloudflare Worker) + this open-source node agent for Microsoft UFO2. The control plane is a credential broker, never an LLM proxy.

CLI: ufoagentd link · ufoagentd run-daemon · ufoagentd update. Build from source with PyInstaller + Inno Setup — see the README.
